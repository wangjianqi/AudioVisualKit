# Security Policy

## Supported versions

This package is currently a pre-release sample. No production support or security response SLA is offered.

## Reporting a vulnerability

**Do not publish exploit details in a public GitHub issue.** Once this project has a public GitHub repository, enable **Private vulnerability reporting** under repository Settings → Security and use that channel. Until it is configured, contact the maintainer through a nonpublic channel.

Please include impacted API/OS version, reproduction steps, and whether real microphone permissions or local file access are involved. Do not include sensitive recorded audio.

## Privacy baseline

The sample microphone adapter processes audio in-memory on-device; the package has no network feature. Consumers remain responsible for user-facing microphone permission rationale, their own privacy policy, and any handling or transmission introduced by their apps.
