# Code of Conduct

This project aims for professional, respectful collaboration. Contributors and maintainers must not engage in harassment, threats, discriminatory language, or sharing private information without consent.

When reviewing issues and pull requests, discuss technical evidence, tradeoffs, and reproducible behavior. Assume disagreement can be handled constructively, without personal attacks.

To report conduct violations, use a private repository contact channel designated by the maintainer rather than posting sensitive details in a public issue. The maintainer may remove offending content or restrict participation when necessary.

Before launching a public community, the repository owner should fill in a dedicated confidential contact address in its GitHub repository settings or `SECURITY.md`.
