## Checks completed here

- Swift syntax parse across project files via `swiftc -frontend -parse`.
- Swift type-check (Foundation-only) of `AudioFrame`, `AudioVisualizationStyle`, and `DemoAudioSignal` on Swift 6.2 Linux.
- SPM manifest parsing and sanitized ZIP structure checks.

## Not verified here

This environment has **no Xcode / Apple SDK / iOS Simulator**; SwiftUI, AVFoundation and Accelerate source code cannot be fully type-checked or executed here. Device frame rate, animation beauty and microphone lifecycle remain unverified. A real iOS Xcode build is a release gate.

## Design decisions

- Missing spectrum data stays at baseline; no fake spectrum is generated by painters.
- Signed PCM and past audio history are separate arrays; existing `AudioFrame` callers remain source-compatible through defaulted initializer fields.
- For very long audio files, snapshots are bounded and time-spaced. File mode is designed as a visual preview, not a laboratory-grade spectrogram.
- Package still has no third-party runtime dependencies and no Actions workflows.
